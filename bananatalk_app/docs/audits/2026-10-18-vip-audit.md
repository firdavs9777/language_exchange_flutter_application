# VIP audit — 2026-10-18

Read-only audit of what VIP promises vs what the code delivers, and which free-user limits are enforced.

## Promised vs delivered
| Promise | Status |
|---|---|
| Ad-free | Delivered |
| VIP badge / frame | Delivered |
| Unlimited AI tutor (free 5/day per feature) | Delivered |
| Who viewed you (free sees 1) | Delivered |
| More visibility (ranking bump) | Delivered |
| Unlimited translations | Partial — 5/day only on chat translate; moments, comments, /translate uncapped |
| Unlimited messages | No difference — free already unlimited (messagesPerDay -1) |
| Unlimited profile views | No difference — checkProfileViewLimit is mounted nowhere |
| Advanced filters | Free for everyone — `_isVip` hard-coded true (community_filter_sheet.dart:167, genders_tab.dart:288); no server check |
| Unlimited daily matches | Not delivered — VIP gets the same 6 cards |
| See who waved | Free for everyone (waves always revealed) |
| Unlimited waves | Free for everyone — WAVE_CAP_ENABLED off |
| Priority support | Not delivered (field only) |
| Study VIP-only features | Nothing locked — STUDY_VIP_ONLY_FEATURES empty |

## Free limits that are enforced
- Moments 10/day, comments 50/day → LimitExceededDialog with VIP (good).
- Tutor 5/day per feature → PersonaUpgradeSheet → VIP (good).
- Visitors: 1 visible → coins or VIP (good).
- Ads for non-VIP with a "remove ads" → VIP link (good).
- Stories 5/day → generic error snackbar (dead end).
- Chat translate 5/day: bottom sheet has VIP; inline offers coins only (dead end for VIP).
- Hourly AI limits → generic error (no `quota_exceeded`, no upsell).

## Leaks / bugs
- Pronunciation score/speak/transcribe and image-vocab grade have no quota (quota charged only at /summary).
- aiRateLimiter ignores the VIP grace period that `tierOf` grants.
- Limit dialog and status screen sell "unlimited messages / profile views" (free already has them); visitor upgrade screen says free gets "50 messages/day".

## Proposed fixes (revenue impact vs effort)
1. Re-gate advanced filters (app + server).
2. Real VIP daily matches (e.g. 15 instead of 6).
3. Replace fake perks in the limit dialog / status screen with real ones.
4. `quota_exceeded` on hourly AI 429s → upgrade sheet.
5. Translation cap on moments/comments/translate routes.
6. VIP option on coin-only sheets; LimitExceededDialog for the story limit.
7. Close tutor quota holes (pronunciation, image-vocab grade).
8. Config: WAVE_CAP_ENABLED, STUDY_VIP_ONLY_FEATURES; fix grace-period mismatch in aiRateLimiter.
