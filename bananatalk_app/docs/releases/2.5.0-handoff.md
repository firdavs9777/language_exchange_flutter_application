# 2.5.0 — what to do on the keystore MacBook (≈30 min)

Same procedure as `2.4.0-handoff.md`; differences only:

## 1. Code
```bash
git fetch origin && git checkout main && git pull --ff-only
git checkout v2.5.0            # tag == main tip (version 2.5.0+10572)
cd bananatalk_app && flutter pub get
```
2.5.0 supersedes 2.4.0 — if 2.4.0 was never submitted, skip it and submit 2.5.0 (it contains everything 2.4.0 did).

## 2. Build
Android: `flutter build appbundle --release -Porg.gradle.java.installations.paths=$J17` → Play Console, version 2.5.0 (10572).
iOS: `flutter build ipa --release` → App Store Connect 2.5.0 (10572). `in_app_review` was added — a clean `pod install` happens inside `flutter build ipa`.

## 3. Device smoke (TestFlight / internal track) — 10 minutes, do before submitting
1. Sandbox coin smoke from the 2.4.0 sheet (steps 1–4) still applies — the money path has never run on a device.
2. **Cold-start push tap**: ask Claude to send you one `lifecycle_waves` test push (it uses the admin broadcast with `data.route=community/waves`). Force-quit the app, tap the push → the app must open on Community › Waves. Then with the app open on Learning, tap another → must switch to Community › Waves. If either lands on Learning, tell Claude (it's a known one-frame race; the fix is small).
3. Profile menu → the "Invite friends" row must be ABSENT (flag off). Register a fresh account → must land on Learning (flag off), no notification sheet on the Learning tab.

## 4. Store "What's new" (paste)
- Daily Matches: six partners chosen for you every day, with the reason each one fits.
- New members get a warm welcome and a few gentle reminders during their first week.
- Invite friends and earn coins when they join (rolling out).
- Notification permission is now asked at the right moment, not on launch.
- Many fixes across stories, reporting, waves, voice rooms and gatherings.

## 5. After approval — server flags (droplet)
```bash
cd /home/language_exchange_backend_application
grep -n "ENABLED" config/config.env | sort      # every key must appear ONCE
# set: DAILY_MATCHES_ENABLED=true  MATCHES_LAYOUT_ENABLED=true
```
