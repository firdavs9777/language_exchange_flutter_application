# 2.4.0 — what to do on the keystore MacBook (≈30 min)

## 1. Get the code
```bash
cd <your checkout of language_exchange_flutter_application>
git fetch origin && git checkout main && git pull --ff-only
git checkout v2.4.0        # tag == main tip 593b2098
cd bananatalk_app && flutter pub get
```

## 2. Android (signed bundle)
`android/key.properties` must exist on this machine (it does on the keystore MacBook).
```bash
J17=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home   # adjust if different there
flutter build appbundle --release -Porg.gradle.java.installations.paths=$J17
```
Output: `build/app/outputs/bundle/release/app-release.aab` → Play Console → Production (or Internal testing first) → version 2.4.0 (10571).

## 3. iOS
```bash
flutter build ipa --release        # or: open ios/Runner.xcworkspace → Product → Archive
```
Upload via Xcode Organizer / Transporter → App Store Connect → 2.4.0 build 10571.

## 4. Sandbox purchase smoke (TestFlight build, sandbox Apple ID)
Do this BEFORE submitting for review — the money path has never run end to end on a device.
1. Coin Shop → buy `coins.100` (sandbox) → balance shows +100.
2. Translate 6 messages (free limit 5) → limit dialog → "Unlock" (50 coins) → balance 50 → translation proceeds.
3. Force-quit, relaunch → balance still 50 (receipt replay must NOT re-credit).
4. Limit dialog → "Watch ad" → rewarded test ad plays → coins credited (ad_reward).
If any step fails: stop, tell Claude the step number; it's a bounded fix.
